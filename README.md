# App de Teste Android

Projeto Android mínimo com uma tela inicial e um botão contador.

## Baixar o APK
1. Abra a aba **Actions** deste repositório.
2. Entre na execução mais recente de **Gerar APK Android** concluída com sucesso.
3. Em **Artifacts**, baixe `app-teste-debug` e extraia o arquivo `app-debug.apk`.
4. Transfira para o Android e instale. Se solicitado, permita instalação desta fonte.

O APK debug é para testes, não para publicação na Play Store. Requer Android 6.0 ou superior.
