# Video Cutter 3s

Android app to select multiple videos and create MP4 clips containing their first three seconds. Processing happens locally on the phone; originals are unchanged. Use the Android share sheet to choose the destination app/tool.

Build: GitHub Actions workflow **Gerar APK Video Cutter 3s**. Download the artifact `video-cutter-3s-apk`, extract it, and install `app-debug.apk`.
